# Dependencies for a demo gamedir under examples/.
#
# Install from *this* directory, with the venv here activated:
#
#     pip install -r requirements.txt
#
# The path below is relative to the working directory, not to this file — pip
# resolves editable paths against the CWD — so running it from anywhere else
# installs the wrong thing or nothing at all.

evennia

# macOS only, and load-bearing there — see the darwin block at the top of
# demo-game/server/conf/settings.py. Without it a daemonized `evennia start`
# deadlocks in the forked child on its first SQLite call, silently. Harmless
# everywhere else.
sqlean.py; sys_platform == "darwin"

# The library under test, installed editable so a change under src/ takes
# effect without a reinstall. That is the whole point of a demo gamedir: it
# exercises the working copy, not a snapshot of it.
-e ..

# The sibling libraries the library depends on. None is published, so pip
# cannot resolve them by name from `-e ..` alone — each needs its checkout
# named here. Editable for the same reason the library above is.
-e ../../evennia-database-cascade
-e ../../evennia-logging-extension
-e ../../evennia-yaml-reader
